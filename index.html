Attention Sentry

A Chrome extension for studying on sites like YouTube, Reddit and Wikipedia. When a site uses a feature built to hold your attention, like infinite scroll, autoplay or view counts, it steps in and tells you which one it is, so you start to notice them yourself.

YouTube view counts are hidden before they ever paint, using a MutationObserver. A jsdom test suite runs the real extension scripts against mocked Chrome APIs on every pull request.

JavaScript · Chrome Extensions (Manifest V3) · jsdom · GitHub Actions

Taxify

A ride-hailing and micro-mobility simulation in Java, built with a teammate during my semester at SLU Madrid. Users on a city grid request taxis and shuttles, share rides, and rent bikes and scooters whose batteries run down and recharge.

It has 30+ classes built around interfaces and the Observer pattern, and 51 JUnit 5 tests, including seeded runs that check after every step that no rider is ever booked twice.

Java · JUnit 5 · Gradle · GitHub Actions
